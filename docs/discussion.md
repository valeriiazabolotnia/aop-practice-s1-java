# 4. Відкрита дискусія

## 1. Чим програма відрізняється від алгоритму?

Алгоритм — це послідовність дій для розв'язання задачі. Програма — це запис цього алгоритму мовою програмування, щоб його міг виконати комп'ютер.

## 2. Навіщо потрібні мови програмування, якщо процесор їх усе одно не розуміє?

Мови програмування дають людині зрозумілий спосіб записувати алгоритми. Спеціальні програми перекладають код у форму, яку може виконувати процесор.

## 3. Чи може комп'ютер зробити щось, чого йому не казали?

Безпосередньо комп'ютер виконує задані інструкції. Але програма може містити умови, цикли та інші правила, через які результат залежить від вхідних даних. Тому може здаватися, що комп'ютер зробив щось не передбачене людиною, хоча він діяв відповідно до написаної програми.

## 4. Чи є рецепт борщу алгоритмом?

Так, рецепт можна вважати алгоритмом. У ньому є певна послідовність кроків, умови та результат. Наприклад, спочатку потрібно підготувати продукти, потім виконати дії у визначеному порядку та отримати готову страву.

## 5. Як зав'язати шнурки людині, яка ніколи їх не бачила?

Потрібно описати кожну дію послідовно і без припущення, що людина вже знає, що таке шнурок. Наприклад: взяти два кінці шнурка, перехрестити їх, протягнути один кінець під іншим, затягнути, зробити петлю, обгорнути другим кінцем петлю та протягнути його через утворений отвір.

## 6. Програма правильно порахувала всі приклади з дошки. Чи доводить це, що вона працює?

Ні. Це показує тільки те, що програма правильно працює на перевірених прикладах. Щоб бути впевненими більше, потрібно перевірити різні випадки, у тому числі граничні та нетипові.
