## 1. Практичні завдання з Java

У роботі виконано дві задачі з LeetCode:

1. **2413. Smallest Even Multiple** — знайти найменше число, яке є кратним і 2, і `n`.
2. **1523. Count Odd Numbers in an Interval Range** — порахувати кількість непарних чисел у діапазоні від `low` до `high` включно.

### Результат

Для першої задачі, якщо `n` парне, відповідь дорівнює `n`. Якщо `n` непарне, відповідь дорівнює `n * 2`.

Для другої задачі використано підрахунок через цілочисельне ділення. Це дозволяє отримати результат без проходження всіх чисел діапазону.
